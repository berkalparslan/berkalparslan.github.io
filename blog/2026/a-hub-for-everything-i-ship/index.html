A hub for everything I ship

17 August 2026 meta

Every app I release needs a support page and a privacy policy before Apple will let it through review. For a while those pages were the only reason this site existed — a handful of documents written for a reviewer, not for a reader.

That felt like a waste. The same address can hold the apps themselves, the reasoning behind them, and whatever I learn along the way. So this is now the one place I point people to.

What lives here

  • The apps — score keepers for tennis, padel, pickleball and volleyball, a health and skincare tracker, a QR toolkit, a decision wheel, and a few small things for fun. Most of them run on Apple Watch.
  • Support and privacy — one page per app, kept where the App Store listing expects to find it.
  • These notes — short posts about decisions I had to make twice.

How the site is built

Plain HTML and CSS, served by GitHub Pages. No framework, no build step, no dependencies to update six months from now. Adding a post means copying a file and adding one line to a JSON manifest.

That constraint is the point. A personal site that needs maintenance stops getting updated, and a site that stops getting updated is worse than no site at all.

If something here is broken or you want to tell me an app is wrong about the score, the support page has the fastest route to me.
