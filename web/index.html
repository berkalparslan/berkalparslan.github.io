  • Store Mockup Studio → App Store / Google Play screenshot generator in the browser: browse the template catalog, start a project, drop your screenshots, write (or let AI write) the captions in every language, then export every store size as a zip. Projects stay on your device. No account.

Store Mockup Studio

A template catalog (60+ designs, filtered by App Store category, store, device and theme) opens straight into the editor: every text, device frame, badge and background is a layer you can move, resize and restyle.

Setup holds the app name, output sizes (iPhone 6.9"/6.5", iPad 13", Apple Watch, Mac, Android phone/tablet, Play feature graphic…) and the languages; App Screens takes one screenshot per device family; captions are stored per language, and the AI panel writes them from a short description when you add your own Anthropic key (it never leaves the browser).

Preview & Export renders every size for every language and hands you a zip organised by language and size. Projects live in the browser and can be exported/imported as a single file; an MCP server and CLI render the same templates headlessly from any AI session.
