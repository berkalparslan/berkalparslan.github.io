Let your coding agent make the screenshots

The MCP server and CLI run the same rendering engine and the same templates as the editor, headless in Node. Claude Code (or any MCP client) can take simulator screenshots, write the captions and render every store size — no browser needed.

Install

git clone https://github.com/berkalparslan/berkalparslan.github.io
cd berkalparslan.github.io/web/store-mockup/mcp
npm install && npm run fonts        # downloads the template fonts once
claude mcp add store-mockup -- node "$PWD/server.mjs"

Cursor and other clients: command node, args ["…/mcp/server.mjs"].

Tools

list_templatesEvery template with key, categories, theme and screen count.
render_screenshotsTemplate + captions (per language) + screenshot files → PNGs organised as language / size / screen.
build_projectSame input → a project file you can import into the web editor for fine-tuning.

Tell the agent

Take 6 screenshots of the app in the iPhone simulator, put them in store/screenshots/src/,
write the captions in English and Turkish, then use render_screenshots with the "pluto" template
for iphone-6.9 and android-phone.

CLI

node cli.mjs templates
node cli.mjs render --template pluto --name "My App" --lang en --lines lines.txt --captions-tr lines.tr.txt \
  --shots ./src --icon icon.png --accent "#12856f" --sizes iphone-6.9,ipad-13,android-phone --out ./out
node cli.mjs project --template pluto --name "My App" --lines lines.txt --shots ./src --out my-app.sms.json

Caption file: one screen per line, Headline [highlight] | Subtitle. Add --captions-<lang> for every extra language.
